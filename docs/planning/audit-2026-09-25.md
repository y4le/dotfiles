### CI and tests

- [x] **M12 — macOS CI fails on tmux 3.7 `list-keys`.** `mk/test-runtime.sh:577`
  and the other single-key checks (about 577–637). In tmux 3.7–3.7c,
  `list-keys -T <table> <key>` sends a single match to a status message
  instead of stdout (fixed upstream in 3.8-rc2), so every single-key grep gets
  nothing. (The failure is confirmed from the CI log; the cause comes from
  reading tmux's `cmd-list-keys.c`, not from running 3.7c.) A tolerant grep
  will not help. Fix: list the whole table
  (`list-keys -T copy-mode-vi`) and grep that, and print `tmux -V` in the CI
  toolchain step.
- [x] **M11 — CI never puts the pinned Neovim on `PATH`,** but `check-vim`
  (`mk/checks.mk:113`) and `mk/test-clipboard.sh` look up `nvim` with
  `command -v` and fail under `CI`. Resolve it with `mk/find-nvim.sh` as
  `test-runtime.sh` already does, and pass it in (`DOTFILES_TEST_NVIM`).
- [x] **M51 — new tests break on macOS temp paths.** `mk/test-filez.sh:55,84`,
  `mk/test-utilities.sh:90`, and `mk/test-nvim-config.lua` compare
  physical paths (`pwd -P`, Vim buffer names) with unresolved `mktemp`
  paths; on macOS `/var` and `/tmp` are symlinks into `/private`.
  Canonicalize the temp root right after `mktemp -d`.
- [x] **M53 — `mk/test-pins.sh` commits fixture repos with the developer's global
  Git config** (about lines 710–741), so it aborts where commit signing or
  hooks are enabled. Wrap fixture Git calls with
  `GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 -c commit.gpgsign=false`.
- [x] **M52 — the tmux runtime test cannot catch config errors.**
  `tmux new-session -d` returns 0 even when the config has errors, and the
  later `source-file`/`bind-key` calls ignore their status
  (`mk/test-runtime.sh:542–605`). Check `source-file` output and status
  explicitly.
- [ ] **M10 (partial) — the real Sheldon and vim-plug cases always skip in CI** because they
  look in the real `$HOME` (`mk/test-sheldon-plugins.sh:385–442`,
  `mk/test-vim.sh:214`). Install the pinned binaries in the networked CI
  prepare step and point the tests at them; verified to pass offline in a
